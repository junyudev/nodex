# Electron E2E triage

Use Electron E2E for behavior that needs real process boundaries, such as
Electron, Core, the Agent Runtime, native input, Windows, or files on disk.
Before changing an untagged case, follow its spec’s recommendation below. Move
behavior to the cheapest layer that can catch a regression and remove the
redundant E2E once that coverage exists.
