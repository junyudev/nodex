The Windows installer and each app update are about 70% smaller. Desktop Tools download in the background when Nodex starts, Codex and Claude Code download the first time you use them, and later updates download a Component again only when it changed. Manage them in **Settings → General → Add-ons**, where you can remove any of them to free up space; after you update from an earlier version, Nodex downloads Desktop Tools once, and Codex and Claude Code once if you already use them.
