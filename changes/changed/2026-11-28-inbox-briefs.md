Messages that Agents, GitHub and Automations leave in your Inbox now read as briefs: their title, then the first three lines, with **Show more** to read the rest in place, so a report no longer fills the whole Inbox. Nodex's suggestion for such a message is now a one-line note on what the chat should do, since the chat receives the message itself, and Agents lead their messages with the point, in your language.
