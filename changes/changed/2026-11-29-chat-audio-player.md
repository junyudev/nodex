Audio in a chat now plays in one player wherever it appears: in a reply, in a tool's result and in a file preview. Each clip shows its name and format with Play, a seek bar and its length, and its menu copies the path, reveals the file, saves a copy or changes the playback speed. Starting one clip pauses whatever else was playing, and every Agent now knows it can show you an audio file by embedding its path, as in `![voice](/path/to/voice.wav)`.
