A chat waiting on a long command no longer shows "Stalled · needs you" in the sidebar and Inbox.
A build or test that ran quietly for more than twenty minutes, in the foreground or as a background
command or Monitor the chat would be woken by, looked like a stall because a command shows no
progress while it runs. Waiting on commands no longer counts toward a stall, and the twenty minutes
start over once the command ends. An Agent that stops responding is still flagged, even while a
command such as a dev server runs beside it.
