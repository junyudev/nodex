A message’s Page now shows what Nodex suggested for it beneath the message, with the same decision the Inbox offers, so you can review a suggestion, see why Nodex made it and decide from the Board without going back to the Inbox. Once the message is sent to a chat, its Page keeps a record of exactly what the chat received, who confirmed it and how Nodex decided, including chats Nodex started for you. Agents can read the same thing: `nodex page show` includes how an Inbox message was routed, and SQL offers `inbox_messages` and `inbox_suggestions`.
