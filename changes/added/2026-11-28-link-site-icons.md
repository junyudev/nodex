Links now show where they go. Every web link in chats, the Inbox and Pages starts with its site's icon, and a link to a GitHub pull request or issue shows the thread's live state; written as a bare URL, it reads as the pull request's number and title instead of a long address. Icons for sites Nodex doesn't draw itself come from Google's icon service, which receives only each site's domain; **Website icons for links** in Settings → General turns that off. Links to this device and private networks never leave it.
