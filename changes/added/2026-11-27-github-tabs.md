GitHub issues and pull requests now open as native tabs. With GitHub connected in **Settings → GitHub**, a link to an issue or pull request in a chat, a Page or the Inbox opens beside your work and shows its state, checks, reviews, description, activity and changed files, plus the Pages and chats linked to it. You can comment, merge, mark it ready, close or reopen it there, and add a comment, review or failing check to a chat's draft. Your browser shortcut and the link menu still open GitHub itself.
