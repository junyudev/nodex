GitHub issues and pull requests now open as native tabs where you can review and land the change. With GitHub connected in **Settings → GitHub**, a link to an issue or pull request in a chat, a Page or the Inbox opens beside your work and shows its state, checks, reviews, description, activity and changed files, plus the Pages and chats linked to it. Review the change there: comment on lines in **Files**, alone or in a pending review, reply to and resolve conversations, mark files viewed, then approve or request changes. React, edit or delete your comments, edit the title and description, filter activity to people's comments, and merge now or when ready. Add a comment, a conversation, every open comment or every failing check to a chat's draft for an Agent to address. Your browser shortcut and the link menu still open GitHub itself.
