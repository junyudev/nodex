A chat whose worktree is gone can keep going in the Project folder. When its working directory no longer exists, the composer says so before you send and offers **Work locally**, which continues the same chat, with its history, in the Project folder; a worktree that was cleaned up with a snapshot also offers **Restore worktree**. A message that couldn't start because its directory was missing is sent once the chat works locally or its worktree is restored, and **Continue in** › **Local** in the summary panel does the same move.
